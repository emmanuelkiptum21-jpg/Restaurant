# Tasty Eataly – Restaurant Website

##  Project Description

Tasty Eataly is a modern and responsive restaurant website built using HTML, CSS, and JavaScript.  
The website allows users to browse food items, search for meals, and add items to a dynamic shopping cart.

This project demonstrates strong front-end development skills including responsive design, DOM manipulation, and interactive UI features.

---

## Features

- Responsive design (Mobile, Tablet, Desktop)
- Add to cart system
- Cart sidebar with dynamic total calculation
- Clean and modern user interface
- Social media footer section

---

##  Technologies Used

- HTML
- CSS (Flexbox & Media Queries)
- JavaScript (DOM Manipulation)
- Font Awesome Icons

---


## Cart Functionality

- Click the "+" icon to add items to the cart
- click on the cart icon
- Cart sidebar slides in from the right
- Total amount updates automatically
- Users can remove items from the cart
